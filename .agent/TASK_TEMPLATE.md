# 任务模板

## 如何使用此模板

1. 复制此文件并重命名为: `[优先级]-[类型]-[简述].md`
   - 示例: `P1-feature-搜索分页功能.md`

2. 填入具体的需求和验收标准

3. 将文件放在对应 Agent 的 `tasks/` 目录中

4. Agent 会自动读取并执行任务

5. 完成后，Agent 会将文件移到 `completed/` 目录
