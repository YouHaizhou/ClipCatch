## 问题 6：本地媒体库时长显示异常（很长的数字）

**文件**：`src/pages/ResourcePage.tsx`（合并后的页面）或 `src/pages/LibraryPage.tsx`

问题原因：`formatDuration` 收到的是毫秒值而不是秒，或者后端返回的 `duration` 字段是毫秒。

**修复**：在调用 `formatDuration` 前判断数量级：
```tsx
// 在 ResourcePage 或 LibraryPage 的时长显示处：
const durationSec = v.duration > 10000 ? Math.floor(v.duration / 1000) : v.duration
<span>{formatDuration(durationSec)}</span>
```

同时检查 `DownloadPage`/下载任务 Tab 中的时长显示，同样处理。

## 问题 7：「我的资源」命名调整 + 正在下载的视频也要体现

**文件**：`src/pages/ResourcePage.tsx`、`src/components/Sidebar.tsx`

### 7.1 命名调整

- Sidebar 导航项 label：`'我的资源'` → `'资源库'`（更简洁）
- 页面内两个 Tab 命名：
  - `'下载任务'` → `'正在下载'`
  - `'本地视频'` → `'我的视频'`

### 7.2 「我的视频」Tab 显示正在下载的视频

在「我的视频」Tab 内容区顶部，若有正在下载的任务，显示一个「正在下载」区域：

```tsx
// 在 LibraryPage 内容区顶部插入（使用 downloadStore 的数据）：
import { useDownloadStore } from '@/store/downloadStore'

const { tasks } = useDownloadStore() // tasks 是 Record<number, DownloadTask>
const downloadingTasks = Object.values(tasks).filter(
  t => t.status === 'downloading' || t.status === 'queued' || t.status === 'paused'
)

{downloadingTasks.length > 0 && (
  <div className="px-5 pt-4 pb-2">
    <p className="text-xs text-muted-foreground font-medium mb-2 uppercase tracking-wider">正在下载</p>
    <div className="flex flex-col gap-2">
      {downloadingTasks.map(task => (
        <div key={task.id ?? task.videoId} className="flex items-center gap-3 p-3 rounded-xl bg-card border border-border">
          <div className="flex-1 min-w-0">
            <p className="text-sm font-medium truncate">{task.video?.title ?? '下载中...'}</p>
            <div className="w-full h-1 rounded-full bg-muted mt-1.5 overflow-hidden">
              <div className="h-full bg-primary rounded-full transition-all"
                style={{ width: `${task.progressPct ?? 0}%` }} />
            </div>
            <p className="text-xs text-muted-foreground mt-1">
              {task.status === 'paused' ? '已暂停' : `${task.progressPct?.toFixed(0) ?? 0}%`}
            </p>
          </div>
        </div>
      ))}
    </div>
  </div>
)}
```

注意：`downloadStore.tasks` 在 `addTask` 时不一定有完整 video 信息，需要做防空处理。

## 问题 8：媒体库排序改为按钮弹出选项

**文件**：`src/pages/ResourcePage.tsx`（LibraryPage 内容区）

将原来的 `<select>` 排序控件改为按钮触发下拉面板：

```tsx
// 状态
const [showSortMenu, setShowSortMenu] = useState(false)

// 排序配置
const SORT_OPTIONS = [
  { value: 'time',  label: '下载时间' },
  { value: 'title', label: '标题' },
  { value: 'size',  label: '文件大小' },
] as const

// UI
<div className="relative">
  <button
    onClick={() => setShowSortMenu(!showSortMenu)}
    className="flex items-center gap-1.5 px-3 py-1.5 rounded-lg bg-card border border-border text-xs hover:bg-muted transition-colors">
    <ArrowUpDown size={12} />
    {SORT_OPTIONS.find(o => o.value === sort)?.label ?? '排序'}
    <ChevronDown size={11} className={cn('transition-transform', showSortMenu && 'rotate-180')} />
  </button>
  {showSortMenu && (
    <div className="absolute right-0 top-full mt-1 z-20 bg-popover border border-border rounded-xl shadow-xl overflow-hidden min-w-[120px]">
      {SORT_OPTIONS.map(opt => (
        <button key={opt.value}
          onClick={() => { setSort(opt.value); setShowSortMenu(false) }}
          className={cn('w-full px-3 py-2 text-xs text-left transition-colors hover:bg-muted',
            sort === opt.value ? 'text-primary font-medium bg-primary/5' : 'text-foreground')}>
          {opt.label}
        </button>
      ))}
    </div>
  )}
</div>
```

需要新增 import：`ArrowUpDown, ChevronDown`（来自 lucide-react）。
