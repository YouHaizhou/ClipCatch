## 问题 4A：媒体库时长显示小数（"7m 6.666666s"）

### 问题现象
本地媒体库视频时长显示 `7m 6.666666666s`，小数要省略。

### 根因
`formatDuration` 中 `seconds % 60` 对浮点数取模会得到浮点结果，后端 `duration` 字段本身就是浮点数（如 `426.666666`）。

### 修复 — 文件：`src/lib/utils.ts`

```typescript
export function formatDuration(seconds: number): string {
  if (!seconds || seconds <= 0) return '0s'
  const totalSec = Math.round(seconds)  // 先取整消除浮点
  const h = Math.floor(totalSec / 3600)
  const m = Math.floor((totalSec % 3600) / 60)
  const s = totalSec % 60
  if (h > 0) return `${h}h ${m}m`
  if (m > 0) return `${m}m ${s}s`
  return `${s}s`
}
```

### 验收标准
- [ ] `formatDuration(426.666)` 返回 `7m 7s`
- [ ] `formatDuration(3661.5)` 返回 `1h 1m`

## 问题 4B：媒体库下载中不显示进度，无暂停/取消

### 问题现象
下载视频时，「我的视频」Tab 顶部不显示下载进度，也没有暂停/取消按钮。

### 根因
`ResourcePage.tsx` 未读取 `downloadStore.tasks` 并渲染活跃任务。

### 修复 — 文件：`src/pages/ResourcePage.tsx`

在组件顶部添加：
```tsx
import { useDownloadStore } from '@/store/downloadStore'
import { proxyImageUrl } from '@/services/api'
import { formatSpeed } from '@/lib/utils'
import { Pause, X, Loader2, Play } from 'lucide-react'

const { tasks, controlTask } = useDownloadStore()
const activeTasks = Object.entries(tasks)
  .filter(([, t]) => ['queued', 'downloading', 'paused'].includes(t.status))
  .map(([id, t]) => ({ ...t, taskId: Number(id) }))
```

在「我的视频」Tab 内容区顶部（视频网格前）插入：
```tsx
{activeTasks.length > 0 && (
  <div className="px-5 pt-4 pb-2">
    <p className="text-xs text-muted-foreground font-medium uppercase tracking-wider mb-2">正在下载</p>
    <div className="flex flex-col gap-2">
      {activeTasks.map(task => (
        <div key={task.taskId} className="flex items-center gap-3 p-3 rounded-xl bg-card border border-border">
          <div className="w-16 h-10 rounded-lg overflow-hidden bg-muted shrink-0">
            {task.video?.thumbnailUrl && (
              <img src={proxyImageUrl(task.video.thumbnailUrl)} className="w-full h-full object-cover"
                onError={e => { (e.target as HTMLImageElement).style.display='none' }} />
            )}
          </div>
          <div className="flex-1 min-w-0">
            <p className="text-xs font-medium truncate">{task.video?.title ?? '下载中...'}</p>
            <div className="w-full h-1 rounded-full bg-muted mt-1.5 overflow-hidden">
              <div className="h-full bg-primary rounded-full transition-all duration-500"
                style={{ width: `${task.progressPct ?? 0}%` }} />
            </div>
            <p className="text-xs text-muted-foreground mt-0.5">
              {task.status === 'paused' ? '已暂停 · ' : ''}{(task.progressPct ?? 0).toFixed(0)}%
              {task.speedBps > 0 && ` · ${formatSpeed(task.speedBps)}`}
            </p>
          </div>
          <div className="flex gap-1 shrink-0">
            {task.status === 'downloading' && (
              <button onClick={() => controlTask(task.taskId, 'pause')}
                className="p-1.5 rounded-md text-muted-foreground hover:text-yellow-400 hover:bg-yellow-400/10" title="暂停">
                <Pause size={13} />
              </button>
            )}
            {task.status === 'paused' && (
              <button onClick={() => controlTask(task.taskId, 'resume')}
                className="p-1.5 rounded-md text-muted-foreground hover:text-primary hover:bg-primary/10" title="继续">
                <Play size={13} />
              </button>
            )}
            <button onClick={() => controlTask(task.taskId, 'cancel')}
              className="p-1.5 rounded-md text-muted-foreground hover:text-red-400 hover:bg-red-400/10" title="取消">
              <X size={13} />
            </button>
          </div>
        </div>
      ))}
    </div>
  </div>
)}
```

### 验收标准
