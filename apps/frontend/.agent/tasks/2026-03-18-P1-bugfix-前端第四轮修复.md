## 问题 2：「我的视频」筛选下拉选项透明，需改为非透明

### 问题现象
用户反映：「我的资源」→「我的视频」界面，点击排序按钮后弹出的下拉选项面板是透明的，看不清选项文字。

### 根因
`ResourcePage.tsx` 中下拉面板使用了 `bg-popover`，而项目的 `popover` CSS 变量未定义或与背景色相同，导致透明效果。

### 修复 — 文件：`src/pages/ResourcePage.tsx`

将下拉面板的背景色从 `bg-popover` 改为明确的不透明色：

```tsx
// 修改前：
<div className="absolute right-0 top-full mt-1 z-20 bg-popover border border-border rounded-xl shadow-xl overflow-hidden min-w-[120px]">

// 修改后：
<div className="absolute right-0 top-full mt-1 z-20 bg-card border border-border rounded-xl shadow-xl overflow-hidden min-w-[120px]" style={{ backgroundColor: 'var(--card)' }}>
```

同时确保每个选项按钮的 hover 背景也不透明：
```tsx
className={cn('w-full px-3 py-2 text-xs text-left transition-colors hover:bg-muted',
  sort === opt.value ? 'text-primary font-medium bg-primary/5' : 'text-foreground bg-card')}
```

### 验收标准
- [ ] 点击排序按钮后弹出的面板背景不透明，选项文字清晰可见

## 问题 3：AI 工作台生成完成显示「0字」，且缺少保存为 md 的选项

### 问题现象
1. AI 生成完成后状态栏显示「生成完成 — 共 0 字」
2. 工具栏缺少「导出 .md」按钮（ExportToolbar 未显示）

### 根因分析

**「0字」问题**：

查看 `WorkspacePage.tsx` 第97行：
```typescript
} else if (event.type === 'done') {
  setState({ ..., stageMsg: `生成完成，共 ${event.wordCount ?? 0} 字`, ... })
}
```

后端 `ai.py` 的 `_run_ai_pipeline` 在推送 done 事件时：
```python
_push(task_id, {
    'type': 'done',
    'note_id': note.id,
    'word_count': word_count,  # ← 后端用 snake_case
})
```

前端 SSE 解析时用 `event.wordCount`（camelCase），但后端推送的是 `word_count`（snake_case），导致始终为 `undefined`，显示「0字」。

**「导出.md 不显示」问题**：

查看 WorkspacePage.tsx 第116行附近：
```tsx
{streamBuffer && stage === 'completed' && currentNoteId && selectedVideo && (
  // ExportToolbar 在这里
)}
```

条件需要 `currentNoteId` 不为 null。但因为 `event.wordCount` 解析失败（undefined），可能导致 `event.noteId` 也未正确读取（后端是 `note_id` 而非 `noteId`）。

检查 `setState` 调用：
```typescript
setState({ ..., currentNoteId: event.noteId ?? null, ... })
//                              ^^^^^^^^^^^^
// 后端推送的是 note_id，前端读的是 noteId → undefined → null
// 导致 currentNoteId 始终为 null → ExportToolbar 不显示
```

### 修复方案

**方案A（推荐）：前端兼容 snake_case**

**文件**：`src/pages/WorkspacePage.tsx`，修改 `done` 事件处理：

```typescript
} else if (event.type === 'done') {
  // 兼容后端 snake_case 字段名
  const ev = event as any
  const wordCount = ev.wordCount ?? ev.word_count ?? 0
  const noteId = ev.noteId ?? ev.note_id ?? null
  setState({
    stage: 'completed',
    stageMsg: `生成完成，共 ${wordCount} 字`,
    isStreaming: false,
    currentNoteId: noteId,
    _sse: null
  })
  sse.close()
  showToast('success', 'AI 笔记生成完成')
}
```

同时检查 `AiStreamEvent` 类型定义（`src/types/index.ts`），确认字段名与后端一致：
```typescript
export interface AiStreamEvent {
  type: 'progress' | 'token' | 'done' | 'error'
  stage?: AiTaskStatus
  message?: string
  content?: string
  noteId?: number    // 前端期望
  note_id?: number   // 后端实际发送
  wordCount?: number // 前端期望  
  word_count?: number // 后端实际发送
}
```

### 验收标准
- [ ] AI 生成完成后状态栏显示正确字数（如「生成完成 — 共 1234 字」），不显示「0字」
- [ ] 生成完成后工具栏出现「导出 .md」按钮
- [ ] 点击「导出 .md」能弹出保存对话框并成功保存
