## 子任务清单

### 模块 1：搜索发现

**1.1 下载时支持画质选择**
- 当前：搜索结果点击下载固定传 `720p`
- 期望：弹出小菜单选择 `1080p / 720p / 480p / 仅音频`，选完再调用 `addTask(url, quality)`
- 实现位置：`SearchPage.tsx` 的 `handleCardDownload`，用简单下拉或按钮组实现

**1.2 搜索结果卡片 Hover 交互完善**
- 当前：Hover 有播放图标覆盖层（已实现）
- 期望：右上角浮出「下载」按钮时，显示质量选择，参考 1.1

---

### 模块 2：下载中心

**2.1 暂停后支持继续下载**
- 当前：`paused` 状态只有取消按钮，没有继续按钮
- 期望：`paused` 状态显示「继续」按钮，点击后调用 `controlTask(taskId, 'resume')`
- 实现位置：`DownloadPage.tsx`，在 `isActive` 判断旁边增加 `task.status === 'paused'` 分支

**2.2 已完成任务增加「发送至 AI 分析」按钮**
- 当前：完成后只有「打开文件夹」
- 期望：增加 `<Cpu />` 图标按钮，点击后 `sessionStorage.setItem('workspace_video_id', task.video_id); setActivePage('workspace')`
- 注意：`task_id` 对应的 `video_id` 已在 API 响应中返回

**2.3 任务分类标签**
- 当前：所有任务混在一起
- 期望：顶部增加 Tab：「全部 / 下载中 / 已完成 / 失败」，点击过滤显示对应任务

---

### 模块 3：AI 工作台

**3.1 Prompt 模板多选**
- 当前：只有「综合摘要」一个模板
- 期望：提供 4 个模板选择
  - `summary`：综合摘要（默认）
  - `timeline`：详细时间轴
  - `meeting`：会议纪要
  - `keypoints`：知识点提取
- 实现：将 `TEMPLATE_KEY = 'summary'` 改为状态变量，UI 显示 4 个按钮组
- 将选中的模板传给 `apiPost('/api/ai/tasks', { ..., prompt_template: template })`

**3.2 Markdown 编辑模式**
- 当前：生成完成后只能查看，不能编辑
- 期望：右上角增加「编辑」按钮，点击切换为 `<textarea>` 可编辑模式，再点「预览」切换回渲染视图
- 编辑状态下的内容用于导出（ExportToolbar 已有导出逻辑）
- 实现位置：`WorkspacePage.tsx`，增加 `editMode` 状态和对应 UI

---

### 模块 4：本地媒体库

**4.1 AI 状态角标**
- 当前：`has_note` 只显示一个蓝色小圆点
- 期望：显示更明确的状态角标
  - 无笔记（`ai_status: 'none'`）：右上角显示灰色 `<Cpu />` 图标，提示「点击 AI 分析」
  - 处理中（`ai_status: 'processing'`）：蓝色旋转动效
  - 已完成（`ai_status: 'completed'`）：绿色对勾
- **注意**：后端 API `/api/library` 目前返回 `has_note: boolean`，后端任务中会新增 `ai_status` 字段，前端需要使用 `video.ai_status` 字段（后端完成后对接）
- 暂时：用 `has_note` 做降级显示（true=绿色对勾，false=灰色 Cpu 图标）

**4.2 排序控件改为按钮组**
- 当前：使用原生 `<select>`
- 期望：改为三个按钮「时间 / 名称 / 大小」，选中高亮

---

### 模块 5：系统设置

**5.1 导航栏底部 API 连接状态指示灯**
- 当前：`Sidebar.tsx` 底部无状态指示
- 期望：在 Sidebar 底部显示各 API 状态
  - DeepSeek：绿色=ok / 红色=error / 灰色=unknown
  - Whisper：绿色=已配置 / 灰色=未配置
- 实现位置：`Sidebar.tsx`，从 `useSettingsStore` 读取 `apiStatus`
- 简洁展示：两个小圆点 + 标签，点击跳转到设置页
