# 2026-03-19-P1-feat-本地资源删除记录与文件

## Git 信息
- 分支：`feature/frontend-resource-delete`
- 基于：`develop`

## 任务概览
本地资源页（ResourcePage）支持删除单条下载记录或同时删除本地文件。

## 问题现象
「本地资源」Tab 的视频列表没有删除按钮，无法清除已下载记录或本地文件。

## 根因
前端 `ResourcePage.tsx` 没有删除操作 UI，后端 `library.py` 没有 DELETE 接口。

## 代码定位

### 后端（`apps/backend/src/routers/library.py`）
在文件末尾添加两个接口：

```python
@router.delete('/library/{video_id}')
def delete_library_record(video_id: int, delete_file: bool = False, db: Session = Depends(get_db)):
    """删除媒体库记录，可选同时删除本地文件"""
    try:
        video = db.query(Video).filter(Video.id == video_id).first()
        if not video:
            return {'code': 1, 'message': '视频不存在'}
        
        # 可选删除本地文件
        if delete_file and video.local_file_path:
            import os as _os
            try:
                if _os.path.exists(video.local_file_path):
                    _os.remove(video.local_file_path)
            except Exception as e:
                print(f'[WARN] delete file failed: {e}')
        
        # 级联删除关联记录（Note、AITask、DownloadTask）
        from models import Note, AITask, DownloadTask
        db.query(Note).filter(Note.video_id == video_id).delete()
        db.query(AITask).filter(AITask.video_id == video_id).delete()
        db.query(DownloadTask).filter(DownloadTask.video_id == video_id).delete()
        db.delete(video)
        db.commit()
        return {'code': 0, 'data': {'success': True}}
    except Exception as e:
        import traceback
        traceback.print_exc()
        return {'code': 1, 'message': f'删除失败: {e}'}
```

### 前端（`apps/frontend/src/pages/ResourcePage.tsx`）

1. 导入 `Trash2` 图标（已在 lucide-react 导入列表中确认是否存在，如无则添加）
2. 导入 `apiDelete` from `@/services/api`
3. 在「我的视频」列表（`LibraryVideo` 卡片）的右上角或操作区加删除按钮：
   - 点击弹出两个选项：「仅删除记录」和「删除记录+本地文件」
   - 实现方式：用简单的 `window.confirm` 两步确认，或直接加两个按钮
   - 推荐方案：hover 显示操作栏，包含「删除记录」（`apiDelete('/api/library/${id}')`）和「删除文件」（`apiDelete('/api/library/${id}?delete_file=true')`）两个按钮
4. 删除后刷新列表（调用现有的 `loadLibrary()` 或类似函数）
5. 下载任务列表（`TaskRow`）也应支持删除已完成/失败的任务记录：
   - 查找现有的 cancel/pause 按钮区域，在 `completed`/`failed` 状态下额外显示「删除记录」按钮
   - 调用同一个 `DELETE /api/library/{video_id}` 接口（用 `task.video_id`）
