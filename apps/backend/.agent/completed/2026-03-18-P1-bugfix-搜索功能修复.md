## 问题 3A：YouTube 搜索修复

**修复**：`_search_youtube` 重构为三个函数：
- `_search_youtube`：入口，优先调 Serper，降级直连
- `_search_youtube_via_serper`：通过 `google.serper.dev/videos` 搜索，未配置 Key 返回 None
- `_search_youtube_direct`：原直连逻辑，失败时给出明确提示「建议配置 Serper API Key」

## 问题 3B：Twitter 搜索修复

**修复**：`_search_twitter` 改用 `/videos` 接口优先，无结果时降级 `/search` 补充，放宽筛选条件（不再强制过滤域名）。
