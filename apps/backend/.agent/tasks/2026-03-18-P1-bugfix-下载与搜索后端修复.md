## 问题 2：Twitter 搜索一直显示「未找到相关视频」

### 问题现象
挂梯子后 YouTube 可以获取视频，但 Twitter/X 无论是否挂梯子，始终返回空，前端显示「未找到相关视频」。用户已配置 Serper API Key。

### 根因
`_search_twitter` 使用 Serper `/search` 接口，该接口返回通用网页结果，twitter 链接极少；筛选条件过严导致全部被过滤。应改用 Serper `/videos` 接口，并在无结果时用 `/search` 补充。

### 修复 — `src/services/search_service.py`

完整替换 `_search_twitter` 函数：

```python
async def _search_twitter(query: str, page: int = 1) -> list:
    """通过 Serper API 搜索 Twitter/X 内容"""
    from database import SessionLocal
    from models import Setting
    import json as _json
    db = SessionLocal()
    try:
        row = db.query(Setting).filter(Setting.key == 'api_key_serper').first()
        serper_key = _json.loads(row.value) if row and row.value else None
    finally:
        db.close()
    if not serper_key:
        return []
    results = []
    try:
        # 第一步：用 /videos 接口专门搜索视频
        async with httpx.AsyncClient(timeout=15) as client:
            resp = await client.post(
                'https://google.serper.dev/videos',
                headers={'X-API-KEY': serper_key, 'Content-Type': 'application/json'},
                json={'q': f'site:twitter.com {query}', 'num': 10},
            )
        if resp.status_code == 200:
            for item in resp.json().get('videos', []):
                link = item.get('link', '')
                if not link:
                    continue
                results.append({
                    'id': link.split('/')[-1] or link,
                    'title': item.get('title', ''),
                    'url': link,
                    'platform': 'twitter',
                    'duration': _parse_duration(item.get('duration', '')),
                    'thumbnail_url': item.get('imageUrl', ''),
                    'author': item.get('channel', ''),
                    'published_at': item.get('date', ''),
                    'view_count': 0,
                })
        # 第二步：若无视频结果，用 /search 补充（放宽筛选）
        if not results:
            async with httpx.AsyncClient(timeout=15) as client:
                resp2 = await client.post(
                    'https://google.serper.dev/search',
                    headers={'X-API-KEY': serper_key, 'Content-Type': 'application/json'},
                    json={'q': f'site:twitter.com OR site:x.com {query}', 'num': 10},
                )
            if resp2.status_code == 200:
                for item in resp2.json().get('organic', []):
                    link = item.get('link', '')
                    if not link:
                        continue
                    results.append({
                        'id': link.split('/')[-1] or link,
                        'title': item.get('title', ''),
                        'url': link,
                        'platform': 'twitter',
                        'duration': 0,
                        'thumbnail_url': item.get('imageUrl', ''),
                        'author': '',
                        'published_at': item.get('date', ''),
                        'view_count': 0,
                    })
    except Exception:
        return []
    return results[:12]
```

## 问题 3：YouTube 挂梯子后可搜索，但下载报「链接解析失败」

### 问题现象
- YouTube 搜索可正常显示视频列表（挂梯子）
- 点击下载后报错：`链接解析失败: ...`
- 报错来源：`routers/download.py` 中 `extract_video_info` 抛出异常

### 根因分析
`extract_video_info` 函数在 `download_service.py` 中，用 yt-dlp 解析视频信息。常见失败原因：
1. yt-dlp 版本过旧，YouTube 更新了防爬机制（最常见）
2. cookies 未配置，YouTube 对某些视频需要登录状态
3. yt-dlp 的 `extract_info` 在 Windows 事件循环中与 asyncio 有冲突

### 修复 — `src/services/download_service.py`

**修复1：升级 yt-dlp 并增加必要 opts**

在 `extract_video_info` 函数中增加更健壮的选项：

```python
async def extract_video_info(url: str) -> dict:
    ydl_opts = {
        'quiet': True,
        'no_warnings': True,
        'skip_download': True,
        'extract_flat': False,
        # 模拟浏览器，避免被 YouTube 拒绝
        'http_headers': {
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
        },
        # 允许使用 po_token（YouTube 新防护机制）
        'extractor_args': {'youtube': {'player_client': ['web', 'android']}},
    }
    ffmpeg_dir = _find_ffmpeg_dir()
    if ffmpeg_dir:
        ydl_opts['ffmpeg_location'] = ffmpeg_dir

    loop = asyncio.get_event_loop()

    def run():
        with yt_dlp.YoutubeDL(ydl_opts) as ydl:
            info = ydl.extract_info(url, download=False)
            if info and '_type' in info and info['_type'] == 'playlist':
                # 若是播放列表取第一个
                entries = info.get('entries', [])
                info = entries[0] if entries else None
            return info

    try:
        info = await loop.run_in_executor(None, run)
    except Exception as e:
        raise ValueError(f'yt-dlp 解析失败: {e}')

    if not info:
        raise ValueError('无法解析该链接，请检查链接是否有效')

    platform = 'youtube' if 'youtube.com' in url or 'youtu.be' in url \
        else 'bilibili' if 'bilibili.com' in url else 'other'

    return {
        'title': info.get('title', '未知标题'),
        'url': url,
        'platform': platform,
        'duration': info.get('duration', 0),
        'thumbnail_url': info.get('thumbnail', ''),
        'author': info.get('uploader', ''),
        'published_at': info.get('upload_date', ''),
    }
```

try:
    info = await extract_video_info(url)
except Exception as e:
    err = str(e)
    if 'Sign in' in err or 'login' in err.lower():

    elif 'Private video' in err:
